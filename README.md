# 🩷 Calculadora Rosa

Aplicação de calculadora desenvolvida em Java, com uma interface gráfica personalizada em tons de rosa.

## 🚀 Tecnologias Utilizadas

* **Java** (100%)
* **Java Swing / AWT** (para a interface gráfica)

## 📁 Estrutura do Projeto

* `CalculadoraRosa.java` - Ficheiro de código-fonte contendo a interface gráfica e a lógica de cálculo.

## 💻 Como Executar o Projeto

### Pré-requisitos
* **Java Development Kit (JDK)** instalado no seu sistema.
